# Spoke & Chain website

Files: `index.html`, `blog.html`, `style.css`

## Deploy on GitHub Pages
1. Create a new repository on GitHub and upload these files to the root.
2. Go to Settings > Pages.
3. Under Branch, choose `main` and `/ (root)`, then Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` within a minute or two.
